## Open source by Lixali Studio

Tools we build for our own products, then publish so you can run them yourself.

### [MakiSend](https://github.com/lixalistudio-oss/makisend)

Self-hosted transactional email API on your own Cloudflare account. Your app sends one `POST /send-email`; MakiSend encrypts and queues the email, delivers it through your own SMTP provider with retries, and shows every send in a dashboard. No per-email pricing.

[Website](https://makisend.lixalistudio.tech) · [Install](https://makisend.lixalistudio.tech/#install) · [API reference](https://makisend.lixalistudio.tech/api/) · [Releases](https://github.com/lixalistudio-oss/makisend/releases)
