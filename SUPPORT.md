# Getting help

Lixali Studio OSS projects are maintained by a small team. Here is the fastest route to an answer.

- **Read the docs first.** Each project's README covers installation, configuration and known limits. MakiSend also has a [website](https://makisend.lixalistudio.tech), an [API reference](https://makisend.lixalistudio.tech/api/) and guides in its `docs/` folder.
- **Search the issues.** Someone may already have hit the same problem: check open and closed issues of the project.
- **Found a bug?** Open an issue with the *Bug report* form. Include the version, the steps to reproduce, and what you expected.
- **Have an idea?** Open an issue with the *Feature request* form, starting with the problem it solves.
- **Security problem?** Do not open an issue. Follow the [security policy](SECURITY.md).
- **Anything else** (partnerships, press, private questions): hello@lixalistudio.tech.

Support is best effort. We do not provide support for instances you run yourself beyond what the issues allow, and we never need your secrets: do not post API keys, passwords or encryption keys anywhere.
