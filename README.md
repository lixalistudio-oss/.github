# .github

Organization profile and default community health files for [Lixali Studio OSS](https://github.com/lixalistudio-oss).

GitHub uses the files in this repository for every public repository of the organization that does not have its own:

| File | Used for |
|---|---|
| [`profile/README.md`](profile/README.md) | The organization's profile page |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Code of conduct |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Contribution guide, linked when someone opens an issue or a pull request |
| [`SECURITY.md`](SECURITY.md) | Security policy, shown under each repository's Security tab |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Bug report and feature request forms |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Pull request description |

A file in a project's own repository always wins over the one here. MakiSend, for example, keeps its own `CONTRIBUTING.md` and templates.

Licenses are not inherited: each project needs its own `LICENSE` file.
